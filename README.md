# Русский перевод встроенной справки Neovim

Переведённые разделы открываются по-русски, остальные — на английском, как
обычно. Английские оригиналы в `$VIMRUNTIME` не меняются.

## Установка

`vim.pack` (Neovim 0.12+):

```lua
vim.pack.add({ "https://github.com/gri3li/nvimdoc-ru" })
```

[lazy.nvim](https://github.com/folke/lazy.nvim):

```lua
{ "gri3li/nvimdoc-ru", lazy = false }
```

Локальная копия (для разработки перевода):

```lua
vim.opt.runtimepath:append(vim.fn.expand("~/src/nvimdoc-ru"))
```

Настраивать ничего не нужно: плагин сам добавляет `ru` в начало
`'helplang'`, включает подсветку для файлов `.rux` и строит индекс тегов.

## Использование

Справка открывается как обычно, `:help {тег}`:

- если раздел переведён, открывается русская версия, иначе английская;
- `:help {тег}@en` — всегда английский оригинал, `:help {тег}@ru` — перевод.

Например, `:help gUU`, `:help :substitute@en`.

Чтобы увидеть список разделов открытого файла справки, нажмите в нём `gO`
(в обычном режиме).  Список откроется в отдельном окне, Enter переходит к
выбранному разделу.

Чтобы временно вернуть английскую справку: `:set helplang=en`.
