# Как переводить

Руководство для тех, кто переводит или обновляет файлы справки.

```
doc/<имя>.rux          перевод (видит :help благодаря 'helplang' = ru)
doc/tags-ru            индекс тегов, генерируется сам, в git не нужен
source/doc/<имя>.txt   английский оригинал, с которого сделан перевод (эталон;
                       есть только у переведённых файлов)
plugin/nvimdoc-ru.lua  helplang, filetype для .rux, автообновление tags-ru
Makefile               команды для переводчика (make help)
scripts/helpdoc.lua    скрипт, который вызывают команды make
scripts/catalog.lua    разделы и темы всех файлов справки (для таблицы в README)
```

## Команды

Все команды запускаются из корня репозитория, список — `make help`:

```sh
make status                 # сводка по всем переводам
make check change.rux       # проверить перевод (без имени — все)
```

Английские оригиналы берутся из справки того Neovim, который запускает
команды: Makefile спрашивает у `nvim` его `$VIMRUNTIME` и показывает путь в
`make help`. Чтобы сверяться с другой версией, укажите её `nvim`:

```sh
make status NVIM=/opt/homebrew/Cellar/neovim/0.12.2/bin/nvim
```

Если нужен только другой каталог справки, есть `RUNTIME=<путь>` (каталог
runtime или его `doc/`).

## Перевод нового файла

1. `make new usr_02.rux`
2. Переводите `doc/usr_02.rux`, сверяясь с правилами ниже.
3. `make check usr_02.rux` — должно быть 0 ошибок.
4. Перезапустите Neovim (или `make tags`) и откройте `:help usr_02.txt`.
5. `make readme` — отметить файл переведённым в README.md.

## После обновления Neovim

1. `make status` — у изменившихся файлов будет «ИЗМЕНИЛСЯ».
2. `make diff <имя>.rux` — посмотреть, какие абзацы поменялись, и перенести
   изменения в `.rux`.
3. `make accept <имя>.rux` — зафиксировать новый эталон (заодно запустит check).
4. `make readme` — обновить таблицу в README.md. Если в Neovim появился
   новый файл справки, `readme` положит его в «Прочее» и попросит дописать
   в `scripts/catalog.lua`; если файл исчез — тоже скажет.

## Правила перевода

Что проверяет `make check` (ошибки):

- первая строка начинается с того же тега файла: `*change.txt*`;
- набор тегов `*тег*` совпадает с оригиналом — ни один не потерян и не добавлен;
- модлайн в конце (`vim:tw=78:ts=8:noet:ft=help:norl:`) сохранён.

Что проверяет `make check` (предупреждения):

- в переводе пропала ссылка `|ссылка|` или появилась новая;
- строка шире 78 колонок (если в оригинале такой же длинной строки нет).

Что не переводится:

- теги `*...*` и ссылки `|...|` — это идентификаторы;
- имена опций в `'...'`, аргументы `{motion}`, `[count]`, `["x]`, клавиши
  `<Esc>`, `CTRL-A`, команды в обратных кавычках;
- код между `>` и `<` (комментарии в коде переводить можно);
- тексты сообщений об ошибках (`E5431: tempdir disappeared`) — пользователь
  увидит их на английском.

Оформление:

- ширина текста — 78 колонок, табуляция — 8; колонки описаний команд
  выравниваются табами, как в оригинале;
- русский текст длиннее английского — абзацы переносятся заново, а не
  обрезаются;
- заголовки ЗАГЛАВНЫМИ БУКВАМИ на кириллице не попадают в оглавление `gO`
  (парсер vimdoc понимает только ASCII). Вместо них используйте заголовок
  колонки `Заголовок ~`, а тег вынесите на строку выше;
- `Note:` → «Примечание:» или «Учтите, что…».

## Глоссарий

| Английский | Русский |
|---|---|
| Normal / Insert / Visual mode | обычный режим / режим вставки / визуальный режим |
| Replace / Virtual Replace mode | режим замены / режим виртуальной замены |
| Select mode | режим выбора |
| Visual block mode | блочный визуальный режим |
| highlighted text | выделенный текст |
| linewise / charwise / blockwise | построчный / посимвольный / блочный |
| motion | перемещение |
| register (unnamed, numbered, named) | регистр (безымянный, нумерованный, именованный) |
| yank / put | скопировать / вставить |
| delete / change | удалить / изменить |
| undo / repeat | отменить / повторить |
| buffer / window | буфер / окно |
| range | диапазон |
| count | число (в тексте оставляем `[count]`) |
| option | опция |
| flag | флаг |
| mapping | привязка |
| pattern / match | шаблон / совпадение |
| substitute | замена |
| filter | фильтр |
| indent / autoindent | отступ / автоотступ |
| white space / blank | пробельные символы / пробел |
| non-blank | непробельный символ |
| line break | разрыв строки |
| comment leader | префикс комментария |
| auto-wrap | автоперенос |
| expression | выражение |
| command-line | командная строка |
| case (upper/lower) | регистр (верхний/нижний) |
| multibyte character | многобайтовый символ |
